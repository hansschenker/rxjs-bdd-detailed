# Package 07 - Accumulation, Feedback, and Recursive Expansion

Package 07 of **RxJS BDD Detailed** studies state accumulation, terminal aggregation, selection, higher-order state feedback, and recursive value generation.

## Operators

1. `scan`
2. `reduce`
3. `count`
4. `toArray`
5. `min`
6. `max`
7. `mergeScan`
8. `switchScan`
9. `expand`

## Central model

```text
ACCUMULATION / FEEDBACK POLICY
=
STATE DOMAIN
+
INITIALIZATION
+
TRANSITION FORM
+
TRANSITION EXECUTION POLICY
+
INFORMATION RETENTION
+
VISIBILITY POLICY
+
COMPLETION POLICY
```

The package intentionally contains nine operators because these form a coherent behavioral family.
