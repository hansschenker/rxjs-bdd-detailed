# Package 06 - Temporal Semantics and Scheduling

Package 06 of **RxJS BDD Detailed** analyzes seven operators through four temporal roles: placement, scheduler boundaries, supervision, and measurement.

## Operators

1. `delay`
2. `delayWhen`
3. `observeOn`
4. `subscribeOn`
5. `timeout`
6. `timestamp`
7. `timeInterval`

## Central teaching model

```text
TEMPORAL SEMANTICS
=
TEMPORAL SUBJECT
+
REFERENCE
+
CLOCK / SCHEDULER
+
STATE TOPOLOGY
+
TRIGGER
+
ACTION
```

This package intentionally contains seven operators. The taxonomy is kept behaviorally coherent rather than padded to an arbitrary count.

See `synthesis.md` for the package-level analysis.
